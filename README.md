# NOVA CAPITAL — Starter Prototype

This is a downloadable frontend prototype with working navigation between pages and illustrative user/admin workflows.

## Included
- Professional dark navy/gold landing page
- Markets list and asset detail pages
- Illustrative chart component
- Login/register form placeholders
- Dashboard with all balances at $0.00
- Deposit workflow marked pending
- Withdrawal workflow marked pending
- Admin overview placeholder
- Privacy and terms placeholders

## Important before real-money launch
This is **not production-ready financial software**. Do not accept real customer funds using this prototype. A production version requires:
- Secure backend authentication and authorization
- Database transactions and audit logs
- KYC/identity verification where required
- Verified payment reconciliation
- Proper withdrawal controls and fraud prevention
- Licensed/approved market-data access
- Secure server-side API keys and environment variables
- Legal, regulatory and compliance review

## Suggested next build
1. Create a GitHub repository.
